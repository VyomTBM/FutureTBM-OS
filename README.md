# FutureTBM-OS
A project I **vibe-coded using the new Gemini 3.8 model.** This is a **futuristic OS with some retro features.** Run entirely in yor browser.

Every **session is temporary and your data stored gets wiped** once you **refresh the page, exit your browser or the kill the tab process**. The data is stored in **IndexedDB.**

## What does it do?
FutureTBM-OS **can do a variety of things.** It can:

* Edit Markdown files
* Manage files
* Simulate a terminal
* Basic Window stuff (Dragging, Maxmizing and closing windows)

## How to run this?
It is very simple. **You just have to download this file as zip from the repository, extract it and open the `index.html` file in any modern browser.**

You can use Git and access the `index.html` from your browser that is stored in the cloned folder.

To use Git to download, paste this command in your terminal client:
```sh
git clone https://github.com/VyomTBM/FutureTBM-OS.git
```
